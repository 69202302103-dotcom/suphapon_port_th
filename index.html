คณะสาธารณสุขศาสตร์บัณฑิต สาขาวิชาสาธารณสุขชุมชน

ศึกษาเกี่ยวกับระบาดวิทยา การส่งเสริมสุขภาพในชุมชน อนามัยสิ่งแวดล้อม การบริหารสาธารณสุข และการดูแลป้องกันโรคติดต่อและโรคไม่ติดต่อในระดับปฐมภูมิ

แผนการเรียน: ห้องเรียนพิเศษวิทยาศาสตร์-คณิตศาสตร์ (Sc)

เน้นทักษะการทดลองทางวิทยาศาสตร์ กระบวนการคิดวิเคราะห์อย่างเป็นระบบ และคณิตศาสตร์ประยุกต์

ประถมศึกษาปีที่ 1 - 6

โรงเรียนอนุบาลอุบลรัตน์

ปลูกฝังพื้นฐานการเรียนรู้ วินัยทางศึกษา และกิจกรรมการทำประโยชน์ส่วนรวม

ความเชี่ยวชาญและความสนใจ

สมรรถนะสำคัญสำหรับงานสาธารณสุขและการส่งเสริมสุขภาพชุมชน

การทำงานร่วมกับชุมชน

ทักษะการสื่อสารเพื่อสร้างความเข้าใจในชุมชน การรับฟังและร่วมวางแผนแก้ไขปัญหาสุขภาพกับผู้นำและชาวบ้านอย่างใกล้ชิด

งานอนามัยและปฐมภูมิ

การปฐมพยาบาลเบื้องต้น การตรวจประเมินสุขภาพชุมชน การคัดกรองโรคเบาหวาน ความดันโลหิต และการดูแลสุขภาพเชิงป้องกัน

การวิเคราะห์และวิทยาวิทยา

พื้นฐานการคิดวิเคราะห์เชิงวิทยาศาสตร์ การรวบรวมข้อมูลสุขภาพประชากรเพื่อประเมินความเสี่ยงและแนวโน้มทางสาธารณสุข

คุณลักษณะเด่น: มีความรับผิดชอบสูง ทำงานเป็นทีมได้ดี พร้อมเรียนรู้สิ่งใหม่ จิตสาธารณะ มนุษยสัมพันธ์ดี

ผลงานและกิจกรรม

ภาพรวมกิจกรรมและการลงพื้นที่ภาคปฏิบัติ

กิจกรรมสถาบัน

กิจกรรมการส่งเสริมสุขภาพในชุมชน

การลงพื้นที่จัดกิจกรรมให้ความรู้ด้านโภชนาการ และการส่งเสริมสุขภาพปฐมภูมิสำหรับประชาชน

ส่งข้อความฝากไว้

วิธีอัปโหลดขึ้น GitHub Pages

ขั้นตอนการสร้างลิงก์เว็บไซต์ออนไลน์ฟรี

1

สมัครและสร้าง Repository บน GitHub

เข้าเว็บไซต์ GitHub.com แล้วกดล็อกอิน/สมัครสมาชิก จากนั้นกดสร้าง Repository ใหม่ (ชื่อ repository เช่น portfolio)

2

ตั้งชื่อไฟล์นี้ว่า index.html

บันทึกโค้ดนี้ลงในเครื่องคอมพิวเตอร์ โดยตั้งชื่อไฟล์เป็น index.html เท่านั้น (เพื่อให้ GitHub Pages ตรวจพบเป็นหน้าแรกโดยอัตโนมัติ)

3

อัปโหลดไฟล์ขึ้น GitHub

ในหน้า Repository ที่สร้างไว้ กด Add file -> Upload files แล้วลากไฟล์ index.html ไปวาง แล้วกด **Commit changes**

4

เปิดใช้งาน GitHub Pages

ไปที่เมนู **Settings** -> **Pages** ในส่วนของ Build and deployment ให้เลือก Source เป็น Deploy from a branch และเลือก Branch เป็น main (หรือ master) แล้วกด **Save**

รอประมาณ 1-2 นาที คุณจะได้ URL เว็บไซต์ Portfolio ออนไลน์ เช่น https://username.github.io/portfolio/ ที่สามารถส่งให้ผู้อื่นเข้าชมได้ทันที!
